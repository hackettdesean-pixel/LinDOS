LinDOS Visual Asset Pack — Extracted Previews
===============================================

What this is:
This zip splits the original promotional/preview graphic you uploaded into
individual PNG files — one per font tile, one per wallpaper — instead of one
big combined image.

Contents:
- Fonts/Category_Samples/   → 20 files, one per font category tile shown
                              (e.g. Futuristic, Cyberpunk, Terminal, Retro...)
- Fonts/Preview_Samples/    → 16 files, one per "LinDOS ___" sample shown in
                              the Preview Grid (Orbit, Edge, Quantum, etc.)
- Fonts/Specimen_Sheet/     → 1 file, the detailed "LinDOS Nova" specimen card
- Wallpapers/               → 5 files, one per wallpaper thumbnail (01–05)

Please note (so there are no surprises):
- These are crops taken directly from the preview graphic you uploaded, at
  whatever resolution existed in that file. The source image was 1536x1024,
  so these are small preview-quality images — not 1000+ separate real,
  installable font files (.ttf/.otf), and not true 8K (7680x4320) wallpapers.
- Each "font" tile shown in the original graphic is a single styled sample
  representing an entire category (e.g. one image stands in for "101
  Futuristic fonts") — the individual fonts within each category were never
  actually present in the graphic, so they can't be extracted from it.
- If you have access to the actual product this graphic is advertising
  (e.g. you purchased it), the real font files and full 8K wallpapers would
  come from that download, not from this promotional image.

Happy to help further — e.g. designing original wallpapers in similar
styles, or building out real usable fonts using web fonts / font tools if
that's actually what you're after.
